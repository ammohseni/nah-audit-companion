# Audit protocol and history

Each audit applies to the manuscript source and claims identified in its
report. Keep completed reports unchanged. After manuscript revisions,
reread the selected source and create a new audit.

Each new audit must contain:

1. audit date;
2. manuscript source and bibliography files;
3. audited claim IDs;
4. `Mathematical assessment`;
5. `Physics-facing action list`;
6. supported claims;
7. `Technical validation`;
8. scope limits.

The `Mathematical assessment` must use stable claim IDs and retain the full
hypothesis, convention, applicability, and implication analysis, including
`INTERNAL ONLY` observations. Line numbers may be included only as secondary
navigation.

The `Physics-facing action list` must contain only `MUST CORRECT` and `SHOULD
CLARIFY` findings and the smallest sufficient manuscript changes. It is the
only source for the `Edit` queue. Process `MUST CORRECT` first, then `SHOULD
CLARIFY`, asking for approval and applying changes exactly one at a time.
Never move `INTERNAL ONLY` observations into this list.
